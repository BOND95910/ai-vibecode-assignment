ทำให้ง่ายขึ้นโดยพฤติกรรมเดิม: ใช้ตัวแยก multipart ของ Node (`Request.formData()`) แทนตัวเขียนเอง · รวมกฎที่เคยซ้ำระหว่าง API กับหน้าเว็บไว้ใน `app/domain.js` (`casesOf` `openDraftsOf` `citizenCase` — B06 เหลือจุดเดียว · `sortQueue` `auditFilters` `holidaysSorted` `ROLES` `DEPTS` `nextSeq`) · 405 ของ Audit มาจาก router แทนกรณีพิเศษ · ตรวจค่าบริการ admin ด้วยตารางเดียว · นับวันทำการหยุดเมื่อพอตัดสินระดับเตือนได้ · `scrypt` แบบ async (ไม่บล็อก event loop) · ไม่เขียนไฟล์ซ้ำตอน reset/clock · ฝั่งเว็บล้างข้อความเก่าก่อนส่งคำขอใหม่ จึงลบโค้ด test ที่เคยลบ DOM เอง (assertion ในลูปจึงพิสูจน์คำขอใหม่จริง ไม่ผ่านด้วยข้อความเก่า) · test ใช้ค่าคาดหวัง/สูตรล็อกอินร่วมใน `tests/helpers.js`

ไม่ทำ (มีเหตุผล): รวมกฎสิทธิ์ UI/API เป็นตารางเดียว (B07/B08 ต้องอยู่เฉพาะ API แต่ B12 ต้องอยู่ทั้ง UI และ API ตาม BUGS.md จึงไม่ง่ายกว่าเดิม และ test ตรวจ UI กับ API คู่กันอยู่แล้ว) · cache เลขบัตรปิดบัง/ชุดแจ้งเตือน (ไม่มีผลที่ขนาดข้อมูลนี้) · ข้าม `tick()` สำหรับไฟล์ static (CONTRACT ให้ประเมินทุกคำขอ)

หลังแก้: `npm test` 51/51 สองรอบติด · เมทริกซ์ BUG_MODE รันใหม่ทั้งบนเครื่องและ Docker (ผลสุดท้ายอยู่ใน `reports/BUG-TRIAGE*.generated.md` และ `reports/logs/bugrun-*-final.log`)
